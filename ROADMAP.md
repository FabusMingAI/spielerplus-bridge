# Roadmap

## v0.2.0 preview

- [x] Shared Home Assistant calendar coordinator and preserved calendar entity identity
- [x] Next training/game, countdown, rolling week and fetch diagnostics
- [x] Change events with quiet initial baseline and rolling-window filtering
- [x] Native-card dashboard template, automation examples, DE/EN entity translations
- [x] German/English READMEs, release notes and fictional screenshot fixtures
- [x] Parser/security/change tests and Home Assistant runtime tests
- [x] Separate aarch64 test installation; production Home Assistant unchanged
- [ ] Publish a reviewed release after CI and review

## Next

- [x] v0.3.0 preview: optional read-only account adapter, locally configured and live-tested
- [ ] Attendance pagination beyond the first five listed events
- [ ] Additional authentication challenge support without weakening account protections
- [ ] User-configurable classification overrides and polling preferences
- [ ] Persist change baselines/history across restart
- [ ] Authenticated remote MCP gateway
- [ ] Automatic dashboard setup with explicit ownership and customization preservation
- [ ] HACS release packaging and catalogue submission
- [ ] Production deployment with backup, after explicit request

Writing RSVPs, editing events and sending team messages are separate future features, not calendar-subscription capabilities. See [attendance research](docs/ATTENDANCE.md).
